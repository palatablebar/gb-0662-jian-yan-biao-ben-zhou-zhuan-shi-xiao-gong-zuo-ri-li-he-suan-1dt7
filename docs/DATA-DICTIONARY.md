# 时效数据定义

specimen 为字符串标本号，保留前导零。project 对应版本化项目契约。department 是原始科室名称。received 与 released 必须带偏移，存储转换为UTC。urgent为0或1，变成明确布尔值。时间缺失哨兵不计成零周转。

版本以接收时刻匹配[start,end)；无匹配与多匹配均隔离。常规标本按上海时区周一至周五09:00–12:00、13:00–17:00核算，calendar.json中的节假日除外。急诊使用接收至签发的自然分钟。approved暂停先合并，再与可计时区间求交；常规非工作段不重复扣除，未批准暂停不扣除。

时效分钟使用Decimal，超出上限才记超时，等于上限达标。宽限为0至60分钟。签发早于接收、无偏移、超过31天等全部隔离。空文件、仅表头和全空行分别返回EMPTY_FILE、HEADER_ONLY、BLANK_ROWS。

同一标本完整字段相同只保留最早来源，其余隔离；同一标本字段冲突全部隔离。批次摘要包含原始字节与三个规则文件摘要及规则版本，参数变更产生新批次。P50/P95使用最近秩，空科室没有分位值。

## 节假日历更正与正式结论

复核发现某天临时停诊/恢复工作时，不追改原批复：更正生成新的正式结论（`status=official`），原批复保留为 `superseded` 并记录 `superseded_by`、`superseded_at`，其净分钟、结论、证据与原始标本全部不变。更正批次与普通批次共用 `runs` 表，`id` 仍由原始标本摘要、参数、三个规则文件摘要与规则版本决定；日历加入摘要，故日历变化必然产生新批次。

`corrections` 表按 `(base 批次, 原始标本摘要, 增删日期, 规则版本)` 生成幂等键：同一更正重试返回已发布的结论且 `replayed=true`，不新增批次或更正记录。更正批次仍需通过行数守恒与证据检查；任一标本被原批复确认的证据（行号+原因码+原始字段）在新结论中缺失时，整次更正取消。`calendar_state` 保存当前生效日历，后续重新核算沿用，避免把临时停诊悄悄改回去。

更正前的原始标本字节随批次存入 `runs.raw`，缺失则拒绝替换（`RAW_MISSING`）。切换在单个 `BEGIN IMMEDIATE` 事务完成：新结论、旧批复替代标记、更正记录与生效日历同时落库；任一步失败整体回滚，旧正式结论继续服务。复核页“更正对照”按标本列出净分钟、超时分钟、结论与来源（批次号+日历摘要）的前后值。
